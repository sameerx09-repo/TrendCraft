# TrendCraft

Brand content workspace built with Next.js, React, Drizzle/PostgreSQL, Inngest,
and Remotion.

- Brand accounts and isolated workspaces
- Trend discovery and reel remixing
- AI persona and product-ad generation
- Preview-first campaign planning and approval
- Content library, review, rendering, and export
- Engagement campaign integration with SwayBees

## Development

The application lives in `web/`. See [web/README.md](web/README.md) for setup,
required environment variables, background jobs, and test commands.

This repository contains source code, not a copy of the live workspace.
Credentials, databases, brand uploads, generated media, captured provider
fixtures, and internal planning notes are intentionally excluded. Provision
licensed media and test fixtures separately to exercise media workflows.

Read [SECURITY.md](SECURITY.md) before committing or publishing changes.
